## 우아한 테크코스 글쓰기

1. 나의 우테코 생활 기록기
   저는 늘 무언가 순간에 생각나는 요소들을 메모하고 나의 일상을 기록해나가는 것을 좋아합니다. 그런 강박을 가지고 살아가고 있었는데 우테코를 합격한 순간부터 블로그를 쓰기 시작하였고 지금까지도 매일 하루에 있었던
   일들을 정리하고 주말에는 일주일 있었던 일을 회고록으로 정리하면서 블로그글을 올려가고 있습니다. 아마도 이것이 우테코에서의 저의 가장 큰 변화가 아닐까 싶습니다. 처음에는 마인드도 “글을 쓰긴 하지만 누군가에게
   공개하면서 이 개념은 아닌거 같다. 글을 쓰는 솜씨가 별로인거 같다.”라는 소리를 들을까봐 공개하지는 않았었는데 코치님들의 말씀과 여러 소프트 스킬 수업을 들으면서 “틀려도 된다. 완벽하고자 하려고 하면 더
   완벽하지 못하게 된다. “ 라는 말을 듣고 많은 이들이 있는 8기-잡답 채널에 올려서 많은 이들의 리뷰를 DM으로 받게 되었다. 이에 용기를 얻어서 매주 회고록을 작성해나갈 수 있었던 것 같습니다.
2. 열심히 몰입하고 학습하는 주변 사람들에게 받는 에너지
   처음에는 솔직히 우테코 생활에 집중하지 못하고 여러 기존에 하던 학교 일이나 외부적인 요소에 힘을 분산해두었던 것 같은데 시간이 지나면서 하나하나 쳐내가고 우테코 생활에 집중할 수 있도록 했던 것 같습니다.
   “포수타” 시간에도 분명 열정적이고 다 안고가고 성장하고자 하는 것은 좋으나 포기하고 덜어낼 용기 또한 필요하다고 해주셔서 어떠한 모집 공지나 활동에 대한 공지가 올라와도 다 참여하고자 하는 강박을 줄이고 나의
   스케줄을 다시 확인하는 시간으로 밸런스를 맞추어가고자 하는 삶을 살게 된 것 같습니다. 또한 페어프로그래밍을 진행하면서도 페어의 열정에 나도 힘입고 같이 만들어가는 미션에 만족을 불어넣어주고자 더 노력하게
   되었던 것 같습니다. 이에 이어서 6시 이후에도 같은 방향으로 나아가고자 하는 사람들과 남아서 토론도 하고 문닫고 가기를 자주 실천했던 것 같습니다.
3. 새로운 도전의 첫 걸음, “연극” 도전과 이어지는 테코톡, 인터뷰
   처음에 우테코 건물에 와서 모두들 아무도 모르는 사람들과 만나게 되고 자기소개를 빠르게 하고 “연극”이라는 고난 미션이 주어지게 되었는데 아직 서로를 모르는 사람들과 연극까지 하라니 참 어려운 상황이였습니다.
   근데 지금 글을 써 내려가면서 다시 회상을 해보는데에도 막상 지나면서 별거 아닌 상황들이 많고 쓸데없는 걱정. 잘해야한다. 완벽해야한다 라는 걱정이 있었는데 연극, 테코톡, 인터뷰 등의 도전을 진행해나가면서
   무언가 해야하는 것에 대한 걱정이 줄어들고 도전정신이 강해질 수 있었던 것 같습니다.
4. 페어 프로그래밍
   우테코에 와서는 기존에는 진행해보지 못했던 “페어 프로그래밍”이라는 과정을 통해서 한 명의 노트북을 사용해서 1명은 드라이버, 1명은 네비게이터가 되어서 1개의 미션을 완성해나가는 방식이였는데 이러한 특이한
   방식을 통해서 각자의 코드를 작성할때에 자신의 코드 작성법에 대한 철학을 가지고 나아갈 수 있게 된 것 같습니다.
