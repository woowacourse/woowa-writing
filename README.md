# 나는 어떠한 사람인가

### ground mind : 화살

너는 어떤 상황 속에서 화를 내는가
너는 어떤 말에 예민해지는가

나는 스스로에게 이러한 질문을 하며
내가 안에 깔린 기저 사고를 마주했다

사람들에게 눈치 주는 너의 말
도전하려는 이들의 방향을 흐리는 너의 말

주도권을 쥔 사람이 바뀌자
너의 판단도 함께 바뀌었다
그리 쉬운 것이었구나

하지만 나의 판단은 그대로다
너의 말이 부정적이든 긍정적이든
그로 인해 나의 방향이 바뀌는 일은 없다

이는 그리 쉽게 바뀌지 않을 것이다



나는 너에게 "눈치 보지 말아라" 라고 말하지 않겠다
상황이 너를 그렇게 만들었을 뿐, 그것은 너의 잘못이 아니다
대신 이렇게 말하겠다

눈치보게 만들지 말아라



타인의 도전에 너그러워라
타인의 시도를 묵묵히 응원하라


판단할 것은 그것이 아니다

판단하기에 너무나도 많은 경우의 수가 있다
그만큼 타인을 잘 안다고 자부할 수 있는가

그렇다면 판단의 화살은 어디를 향해야 할까
나보다 나를 더 잘 아는 사람은 없을 것이다

### vision : 선, 점

'#1'
나는 문제를 손에 쥐고 돌려보는 것을 좋아한다
끝이라고 생각한 끄트머리까지 도달한 후
보이는 그 가장 견고한 선

수학 문제를 풀 때도 마찬가지이다
공식이 아닌 원리 자체를 가지고 비틀며 풀어낸다
여러 가지 방식으로 풀어볼 수록
원리를 더욱 깊고 정확하게 이해할 수 있었고 감을 찾아갔다

문제 상황도 같다
상황을 더 깊게 이해할수록
더 다양한 각도로 문제를 돌려볼 수 있고
결국엔 최적의 해결에 가까워진다.

'#2'
나는 양립하는 두 상황이 동시에 본다
그 어느 하나만 선택할 수 없는 애매함이란 특징을 지녔다
장점이 될 수 있을까
?

하나의 정답만이 존재하지 않는 복잡한 문제일수록
단일한 관점으로는 풀 수 없다.
사회적인 문제나 시스템적인 변화 앞에서는
하나의 전문성보다도
서로 다른 분야가 겹치는 교차점을 읽어야 한다
!

'#3'
돌이켜보면
내가 문제의식을 느꼈던 순간들은  
나와 가까운 곳에서 발생한 일이 대부분이었다

그렇다면
내가 더 많은 경험을 할 수록
더 다양한 문제들을 인식할 수 있게 되지 않을까



그리고 그 문제들을 손에 쥐고 돌려보려면  
나는 더 넓은 시야와 더 깊은 이해를 가져야 할 것이다
애매함을 강점 삼아
