다행히 두 번째 발표 이후에는 지난 발표보다 많이 개선되었다는 피드백 받을 수 있었습니다.

그렇게 발표 스터디 뿐만 아니라 다양한 상황에서도 의식적으로 의사를 전달하며 실패하고 학습해나갔습니다.
